# Radar 2030 · Metodología prospectiva

Presentación web interactiva del equipo 2 de la Universidad La Salle Bajío sobre la metodología empleada en *Ingeniería Industrial en México 2030: Escenarios de futuro*.

La experiencia explica tres etapas:

1. Identificación de grupos de afinidad.
2. Determinación de vectores.
3. Identificación de escenarios futuros.

Incluye navegación para exposición, matriz interactiva y un laboratorio de ideas con votación anónima del salón.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

Fuente académica principal: Asociación Nacional de Facultades y Escuelas de Ingeniería (2016).
